# 성적 관리 프로그램

## 무엇을 하나요 (What)
성적 CSV 파일을 읽어 유효한 (이름, 점수)만 골라 내고, 건너뛴 줄은 이유와 함께 기록합니다.

## 왜 만들었나요 (Why)
실제 성적 파일에는 빈 칸 · 범위 밖 점수 · 정수가 아닌 값 · 중복 이름이 섞여 있어 그냥 읽으면 프로그램이 죽거나 잘못된 평균이 나오기 때문입니다.
(※ 이 칸은 본인의 경험과 말로 다시 다듬어 주세요.)

## 어떻게 쓰나요 (How)
```
python load_scores.py scores.csv
```
- 점수는 0~100 사이 정수만 인정합니다.
- 같은 이름이 두 번 나오면 지우지 않고 둘 다 남깁니다(동명이인 가능성).
- 파일이 없으면 `FileNotFoundError`를 그대로 올립니다.

## 어떻게 테스트하나요
```
pip install pytest pytest-cov
pytest
pytest --cov=load_scores --cov-report=term-missing
```

## 데이터

- **출처**: 12주차 수업(AI 협업 프로그래밍)에서 배포한 `scores_2026.csv`
- **크기**: 114행 × 5열 (정제 후 100행)
- **열 설명**

| 열 | 뜻 |
|---|---|
| 학번 | 학생 번호 (문자) |
| 이름 | 학생 이름 (문자) |
| 반 | 1반 또는 2반 |
| 과목 | 수학, 영어, 프로그래밍 |
| 점수 | 해당 과목 시험 점수 (0~100 정수) |

### 정제 규칙

1. 점수가 빈 행 6개 삭제
2. 모든 열이 같은 중복 행 4개 삭제
3. 반·과목의 앞뒤 공백 제거 ('1반 ' → '1반')
4. 점수가 0~100 밖인 행 4개 삭제 (999 세 개, -5 한 개)

### 빈 칸 처리와 그 이유

점수가 빈 행은 **삭제**했다. 점수는 실제로 잰 값이라 0이나 평균으로 채우면
없던 점수를 만들어 평균이 왜곡되기 때문이다. 빈 칸이 6행(약 5%)뿐이라
삭제해도 분석에 충분한 100행이 남는다.
